# 侧栏布局约定

版本：0.2.0-alpha.17。对应 F01 的可拖动侧栏，验证结果见[实施记录](./implementation-status.md)。

## 调整与响应式布局

展开侧栏支持主指针拖动。按下时固定实际边缘、指针和边界，移动超过 2px 才进入调整；只有原指针松开才提交。无移动点击、右键、Ctrl 点击和其他指针不会提交或接管。触控与笔的真实设备验证仍须另外记录，鼠标验收不能代替它们。

展开宽度为 200–420px，并为主内容保留至少 720px。边界按实际工作台容器宽度计算，包含原生滚动条和页面预留空间的扣除；容器变化时重新测量。窗口缩小时限制实际显示宽度，保存的较大宽度继续保留；扩大后恢复。侧栏、主内容偏移、提示位置和分隔器读取同一布局变量。

默认宽度沿用原布局：1200px 以上为 244px，981–1200px 为 215px。980px 及以下自动采用 75px 图标侧栏，450px 及以下为 58px。窄屏自动收起不改写用户的展开选择和宽度；分隔器在窄屏隐藏，原焦点转到侧栏按钮。

## 键盘与取消

分隔器可聚焦，有名称、垂直方向、主面板关联和实际像素尺寸。当前、最小和最大值与实际可用宽度一致，收起时明确说明 Enter 可恢复。

| 操作 | 行为 |
| --- | --- |
| 左右方向键 | 展开时每次调整 10px；已收起时先恢复展开宽度 |
| Shift + 左右方向键 | 展开时每次调整 50px；已收起时先恢复展开宽度 |
| Home / End | 调整到当前窗口的展开下限 / 上限 |
| Enter | 收起 / 恢复，保留分隔器焦点和展开宽度 |
| Escape | 取消在途拖动 |
| 外观 → 恢复默认布局 | 清除自定义宽度，恢复展开和响应式默认值 |

指针取消、丢失捕获、窗口失焦、页面变为隐藏、窗口尺寸变化和组件卸载也结束拖动。取消恢复已提交布局，释放捕获、监听和动画帧，恢复原 body 光标、选择样式及其优先级。每帧只更新 CSS 布局变量和分隔器值；React 偏好在提交时更新。

分隔器两侧的焦点线分别使用侧栏文字色和内容文字色。验收分别核对实际侧栏背景、页面根背景和顶栏背景；透明 body 本身不代表最终绘制的页面背景。

## 客户端保存与同步

独立 `workbench-layout` 记录只包含版本、宽度和展开选择：

```json
{
  "version": 1,
  "sidebarWidth": 320,
  "sidebarCollapsed": false
}
```

`sidebarWidth: null` 表示采用响应式默认值。未知版本、无效 JSON、非有限数值、越界宽度和错误字段类型回到默认布局，不解释为 CSS 或其他代码。

宽度与收起选择在一次提交中保存。同源窗口读取最新记录，旧排队事件不能恢复旧值。在拖动期间延后同步；本地取消后读取最新记录，本地提交则以此次提交为准。清除同源存储恢复默认布局。

存储读取受阻或写入配额失败时，当前窗口仍可调整并显示无法保存。未保存意图不会被页面恢复事件或旧同源记录覆盖；下一次明确调整会重新尝试保存，成功后才清除提示。关闭窗口后的恢复只承诺已成功保存的值。

布局属于当前客户端，跨项目共用。两次真实桌面启动使用同一独立用户目录，分别核对原桌面、核心和 Worker 的正常退出；发行目录验收禁用外部 Java。原有六主题的 12 项桌面验收保留，侧栏检查另行计数和归档。

## 证据边界

浏览器测试覆盖真实鼠标操作、键盘、响应式布局、实际同源窗口事件和存储失败。派发 blur、pointercancel、pageshow 等事件只验证相应处理路径，不作为真实系统失焦、完整 BFCache、触控设备或长期运行验收。原生窗口尺寸、渲染器重载和完整退出重开由桌面脚本另验。

F01 的 PTY、终端重连和其他 F01–F21 / M0–M3 条件继续实施。此项布局交付不会改变这些剩余工作的完成状态。
