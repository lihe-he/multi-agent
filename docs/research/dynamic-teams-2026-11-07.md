## 主要设计与审查结论

- 采用当前 Java/SQLite 调度层扩展实际实体，不通过新建根任务模拟后代。副任务、运行身份和根累计数同事务创建；模型请求仍在同一根预算事务承诺。
- 任务开始前固定定义版本、额外数据发送路由与根限制。UI 携带当前展示版本，409 时保留输入并刷新核对；运行时停用定义/路由能够撤回新增调用。
- 文件访问同时检查能力和多层范围，枚举/检索在计数前过滤。命令和 MCP 无法证明窄文件边界，移交获授权根阶段。固定 MCP 来源来自实际成功模型回执，父引用不会替换原子执行者。
- API 模型容量仅在实际请求内持有，工具、快照、依赖和等待不占模型槽。工具与写入另有资源申请，父子持有独立可写现场。原生 CLI 无可确认挂起，因此本轮明确拒绝其动态委派。
- 依赖只引用同父已创建副任务，消除动态父/后代回指。整合依赖后更新基线；如果继续对旧基线检查只读副成果，会把依赖写入误判为副任务越权，此缺陷已修复并由真实 Git/HTTP 场景覆盖。
- 采纳预检全部文件、成果版本、父版本与 index 后再写。冲突拒绝不触碰其他文件，写入中断保留 UNKNOWN。执行位交接保全父已经暂存的内容 blob，不把子暂存内容顺带覆盖父暂存区。
- 采纳回执与 integrations 同事务保存，终态事实不可覆盖。未知采纳既不能用原编号重放，也不能换编号绕过；根任意未知操作停止新委派和工具。只读副结果不能被标成已采纳文件。
- 独立提案和审查无共享团队工具/收件箱，持久层也校验来源种类。团队消息保留原模型和工具来源，用户只能产生 USER 来源；消息内容不增加授权。
- 模型收件箱从零正序分页，避免初次只取最新页丢掉较早资料。消息重试编号和草稿跨页面/重载保存，成功 POST 清除意图不依赖下一次轮询。
- 严格校验定义版本、限额、开关和范围类型，拒绝把分数/字符串静默转换为整数或把无效范围放宽为全项目。旧版固定阶段保持既有路径，本轮没有宣称全部历史权限声明已强制执行。

## 实际验证

`TeamExecutionTest` 使用真实 HTTP、Git、资源管理器、持久层和引擎，覆盖实际写入/依赖/采纳/消息、容量二下两个父执行者等待、在途子请求取消及重开 UNKNOWN、父修改冲突、真实两层递归与累计限制、独立提案输入输出隔离、定义撤回及子 MCP 原来源与父去重引用。

`RuntimeDelegationTest` 先制造 2105 个排除文件再检查范围内文件，覆盖工具能力裁剪、模型回执后容量释放、范围逐层交集、多文件冲突不写入，以及父暂存 blob 和执行位保全。`TeamRecordsTest` 覆盖队列事务故障回滚、稳定身份、结束不可覆盖、来源伪造、版本/路由/非法输入、消息历史与长工具编号、未确认重放拒绝和采纳事务故障。

浏览器协议测试在 1440px/430px 检查定义编辑、过期版本、额外路由确认、执行前冻结计划、团队状态/依赖/权限/来源、请求与原证据定位、历史游标、消息回执丢失后的切页/重载/原编号重试、结束重试解锁以及 CLI 委派不可用。截图经过实际查看。

Jar 集成增加两名真实副任务、依赖只读成果、父新增文件保全、采纳、原模型/工具来源、共享根调用和 MCP 一次派发；解压实际交付 ZIP，核对团队、消息、采纳、MCP 与请求记录。独立生产 Web 经真实同源代理，在副 HTTP 请求在途时关闭会话、浏览器和附加桌面，重新核对原请求未重放，再完成团队与独立审查。该场景显式配置额外子路由，保留根引擎/模型锁定，父等待时只有实际子 HTTP 请求占用一个模型槽。

完整次数、打包和三端 CI 结果以[实施记录](../implementation-status.md)中的具体提交与报告为准。本机模型/MCP 是确定性协议端点，不能作为外部供应商、官方登录、移动端或系统桌面能力验收。

## 失败与修正记录

早期真实 Team 用例把第二个根任务复用为同一目标，被既有去重门禁拒绝；夹具改为不同实际目标，保留产品规则。委派测试最初仍按固定流水线 DESIGN 匹配 LEAD，修正为实际 INVESTIGATE。

首轮八项浏览器测试中四项失败：能力列表嵌套在通用 Field 中，所有复选框被关联到同一标签；恢复后的 textarea 文本参与隐式 label 匹配。能力组改为各自标签，消息输入使用明确 Field 关联，随后全部 29 项通过。窄屏截图另发现复选框继承全宽输入导致文字竖排，增加局部两列布局并重新验证两个宽度。

最终校验期间一次完整核心运行在 MCP 测试的 HttpServer 初始化处遇到 Windows/JDK 本地通道 `Address already in use: connect`，未进入该测试断言。新增输入边界用例同时误给已运行的 Agent 再建立执行意图，被运行状态门禁拒绝；改为独立文件操作意图后核对 UNKNOWN 根效果。两份失败报告保留在 `.runtime/alpha8-regression-attempt1/`，重新执行最终回归；失败不计为通过，也不通过放宽产品停止或测试断言隐藏。
