## 实现选择

六套外观共同定义文字、表面、输入边框、焦点、状态、侧栏、代码和 Diff 颜色。七份既有业务 CSS 使用统一语义颜色，保留布局和原注释，并新增外观样式。每套包含 63 个颜色变量，预览缩略图直接使用相应主题的变量。

`web/public/theme-init.js` 是应用入口之前执行的外部脚本。生产 CSP 保留 `script-src 'self'`，Vite 将公开脚本引用转换为相对地址，使独立静态 Web 和 Electron 文件来源都能加载。该脚本创建唯一的外观存储，React 通过 `useSyncExternalStore` 读取同一份状态。默认跟随系统：系统浅色使用青瓷，深色使用墨夜；选择固定主题后，系统变化不覆盖选择。

选择使用 `workbench-theme` 保存在当前客户端的 localStorage。只接受七个固定值，旧值和无效值回到系统，不把存储内容作为 CSS 或 HTML。同源事件重新读取最新值，避免旧排队事件恢复已经过时的偏好；清空存储回到系统。系统主题变更、页面恢复和主题色元数据使用同一应用函数。

浏览器无法读写存储时，当前窗口仍可选择主题，并明确显示无法保存。项目和会话选择同样保留内存回退，连接令牌仍使用原 sessionStorage 范围；令牌保存失败后，本次窗口的已验证连接继续可用。没有将令牌加入主题存储或静态配置。核心不可用时，外观页面仍可使用；离线页脚从客户端包版本读取实际版本。

Electron 原窗口在 `ready-to-show` 后显示，来源是稳定的 `web/dist/index.html` 文件。桌面验收使用两次真实应用启动和同一独立用户目录，分别核验完整关闭后的偏好恢复、浅深色切换和渲染器重载，并用原 PID/出生的独立探针核对桌面、核心和 Worker 已停止。
