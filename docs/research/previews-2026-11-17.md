# 会话预览研究与实现

日期：2026-11-17。目标为 F05 的本机桌面预览：会话隔离、端口绑定、真实登录态、关闭与清理。具体行为见[预览约定](../preview-contract.md)。

## 固定来源

本轮参考 OpenCode 的浏览器策略、IPC、页面状态同步、恢复及测试结构，固定提交为 `59ed43f0b8da891f03a7333d540a7b0c428049ea`。未复制其实现。原下载字节、SHA-256、Git blob 和逐项核对结果保存在 `.runtime/alpha21-preview-references-attempt1/sources.json`，整理清单见[来源回执](./preview-sources-2026-11-17.json)。

Electron 固定为安装版本 `39.2.7`，上游 tag 对应提交 `4d18062d0f0ca34c455bc7ec032dd7959a0365b6`。阅读其 WebContentsView、Session、权限处理、安全导航与清理 API 文档；原字节与 blob 核对保存在 `.runtime/alpha21-electron-preview-references-attempt1/sources.json`。Electron 沿用现有发行依赖与许可文件，本轮没有新增第三方运行时依赖。

## 实现选择

核心管理配置与页面实际浏览数据分离。管理端口在预览所有请求中拒绝，避免将管理凭据与项目页面放进同一可执行上下文；每个核心、项目、会话和存储代次使用独立持久分区。端口授权采用每会话明确整数集合，并区分配置版本与撤权版本，避免切换标签误清除登录态。

持久 URL 剥除 query/fragment，原生页面保留完整登录回调。实际打开在串行宿主内先保存再一次加载，页面自行导航只更新脱敏元数据。活动标签由明确选中操作保存，后台页面导航不抢占选择。分区持久账本支持完整退出后的旧代次清理，失败时保留原记录。

原生视图不受 DOM 层级自动裁剪，因而显式计算可视矩形、避开顶部导航，并在弹窗、任务详情、会话切换或离线时销毁页面。暂停后以原持久分区恢复，页面内存状态不承诺恢复。

## 验证与原失败

最初完整 UI 回归因旧接口夹具返回 `{}` 导致预览组件调用缺失数组而白屏；已增加能力结构核验，旧会话界面正常显示。后续完整 229 项生产 UI 回归通过，最终源码更新后另行重新验收，以最新准确回执为准。

真实主程序验收前两次因测试工具错误导入不同版本 Playwright 的断言而失败，原回执分别保留。第三次原生页面已加载但测试尚未滚到足够可见的区域；产品补充交集裁剪，测试显式滚动。第四次切换会话后只等待页面数量，尚未等待实际页面加载完成，原失败保留并修正等待条件。第五次实际主程序七组检查通过；第六次修正登录夹具只在带 code 的回调写入 Cookie，避免普通重开伪造登录恢复，另加入工作台弹窗暂停覆盖。后续增加项目隔离及旧分区 Cookie 为空的独立检查，最终结果写入[原生验收](../qa/preview-native-win32.json)。

上述原失败现场为 `.runtime/preview-native-ad22qO`、`preview-native-p39aEl`、`preview-native-eFjOR8`、`preview-native-q9nTTh`；原成功与后续运行分别保存在各自随机目录中，没有把失败改写为通过。原型研究另有 Cookie、Service Worker、权限及 beforeunload 试验，不能代替当前产品主程序验收。

最终九组主程序验收位于 `.runtime/preview-native-8PirVm`，全部当前输入摘要再次核对。三次完整桌面/核心/Worker退出的原PID与出生时间独立核验通过。原生页面使用`WebContents.capturePage`单独捕获，主渲染器截图只作为工作台外壳证据；不能用主渲染器截图的空白区域推断原生页面是否渲染。

发行入口在 `--packaged` 下复用现有产物冻结工具，核对包内Jar、全部桌面/Web与JRE文件，并运行实际发行可执行程序；探针由开发JDK编译，运行与原身份核验使用包内Java，发行程序的PATH不包含外部Java或Node。Windows两次九组均通过，后一次在独立非输入测试桌面执行，现场为 `.runtime/preview-native-packaged-u3DY9H`；原开发验收和两次发行结果分别保留。31份桌面/Web及207份JRE字节再次核对，12个原进程身份停止，安装器和外部OAuth仍单独验收。正式结果见[发行预览回执](../qa/alpha21-packaged-preview-validation-win32.json)。
