# 逐文件差异约定

alpha.18 在任务“代码差异”页提供文件树、原行/新行、增删高亮及明确的预览状态。这个视图比较本次读取时固定的 Git HEAD 和实际任务目录内容，基线 SHA 与内容版本一起显示。任务目录之外的原项目采纳、按轮次撤销和检查点恢复另有写入事务要求，仍在后续范围。

## 读取与版本

管理 API 的 health 和任务快照声明 `diffViewProtocolVersion: 1`。公开 API、Worker 帧、SQLite 和文件工具协议分别保持 1、1、8 和 2。读取使用原管理令牌，接口不领取根写入保护或消耗模型预算。

```http
GET /api/tasks/{id}/diff-view?path=&expectedVersion=&expectedBase=
Authorization: Bearer <当前核心令牌>
```

第一次请求可省略三个查询参数。返回完整变更清单，并选中清单的首项；没有现场或没有变更时 `preview` 为 `null`。选择文件时须把返回的 `version`、`baseline` 和清单中的相对 `path` 带回。前端使用 URL 查询编码，路径和代码通过 React 字面文本呈现。

| 字段 | 含义 |
| --- | --- |
| `protocolVersion` | 当前为 1 |
| `workspace` | 任务现场；未准备时为空 |
| `version` | 原 `agent-workbench-content-v2` 指纹算法产生的内容版本 |
| `baseline` | 同次读取固定的 HEAD 对象 SHA，支持 SHA-1 与 SHA-256 仓库 |
| `files` | 完整变更清单，每项包含路径、ADDED/MODIFIED/DELETED、原/新模式、大小、SHA-256、原/新 Git blob 和排除标志 |
| `selectedPath` / `preview` | 实际选中路径及该路径的字节版本、原 blob、大小、状态、差异块和逐行数据 |
| `complete` | 清单完整；不表示每个文件都允许文本预览 |
| `consistency` | `CAPTURED_FILE_DIGESTS`，预览字节必须匹配捕获清单中的摘要 |
| `limits` | 文件字节、变更文件数、差异行数与并发读取者上限 |

清单来自同一次原指纹遍历捕获的存在状态、index 模式、实际执行位、大小、SHA-256 和 Git blob 摘要。普通指纹调用不增加 Git blob 哈希，原版本算法保持。清单按原始内容与有效模式比较固定树；重命名作为删除和新增分别显示。忽略且未跟踪的文件不在原指纹范围内，已经跟踪的忽略文件仍参与比较。

仅选中文件读取有界原字节，读取结果再次核对捕获的大小和 SHA-256；固定 Git blob 核对大小和对象哈希。两个已核验副本存入数据目录下的独立临时目录，用原管理进程路径调用 Git `diff --no-index`，禁用外部 diff、textconv 和颜色，固定 Myers、三行上下文、无重命名和缩进启发式。`diff.suppressBlankEmpty=false` 保留空上下文标记。

解析后逐行核对原/新坐标、内容、末行换行和差异块之间省略的区间；完整行数据必须能重建捕获的新文件。最终重新检查原内容版本、HEAD 和未合并 index。变化返回 409，不发布部分结果。选中字节的 A→B→A 改写不能以最终指纹相同为由带入中间内容。

此保证针对捕获的文件摘要，不是操作系统对整个目录的原子快照。不能一般性证明读取期间所有文件从未变化；后台 Git 与文件工具保持原 `OBSERVED_ONLY` 进程覆盖语义。生产预览由核心执行，预览 Git PID 未保存到 Worker 执行账本；实际任务模型和文件操作仍由原 Worker 完成。

## 行数据与状态

`hunks` 保存 `oldStart/oldCount/newStart/newCount`；每行保存 `kind`、字面 `content`、`oldLine/newLine` 与 `noNewline`。ADD 的原行为空，REMOVE 的新行为空，CONTEXT 同时有两边行号。代码自身以 `+` 或 `-` 开头时仍保留原内容，不作为新的差异头解析。CRLF 和末行无换行分别保留事实。

| `preview.type` | 展示与完整性 |
| --- | --- |
| `TEXT` | 已核验的完整差异块；包含增删与行数统计 |
| `BINARY` | 含 NUL 或无法完整解码为 UTF-8，显示元数据，`complete=false` |
| `EXCLUDED` | 原内部/敏感路径策略，显示元数据，原 blob 大小可未读取；不返回文本 |
| `LIMIT` | 文件、补丁输出或差异行超限，明确 `limit`，没有截断行数据 |
| `MODE_ONLY` | 内容相同，仅执行位变化 |
| `EMPTY` | 新增或删除空文件 |
| `UNSUPPORTED` | Git 输出无法与捕获字节完整对应，保留不完整状态，无推测行号 |

每文件文本最多 256000 字节，每次最多 2000 个变更文件，最多 5000 行，并发读取者最多两个。变更清单超限返回 413；读取者已满返回 429。路径越界、Git 子模块/符号链接及原指纹不能表示的全空白文件名返回明确错误，未解决合并冲突返回 409。临时目录及文件在写入和清理前核对真实绝对路径与原生身份；拒绝链接、junction 和替换，只删除本次拥有的两个副本及空目录。

## 前端与旧接口

文件树支持文件夹折叠、单个键盘停靠点、上下方向、Home/End、左右展开/返回、Enter/Space。宽度不超过 760px 的差异容器将树与预览上下排列；长行在代码区域横向滚动。沿用原六套主题变量。

读取新文件、刷新或切换任务立即清除旧行；Abort 与请求序号一起拒绝迟到响应。任务版本或现场变化触发重读，手动刷新尽量保留仍有变更的选中文件。30 秒请求超时与服务器错误显示警报并结束加载。响应校验绑定清单、选中路径、版本、摘要、行坐标及差异块计数；前端不另行声称对服务器字节做密码学重算。

原 `/api/tasks/{id}/diff` 保留 `diff/version/workspace`，新增基线、完整性和文件计数；文本也从同次已核验预览生成，最多 20 个文件及 512000 字符，二进制、排除或超限项明确省略，`truncated` 如实为 true。没有协议标记的旧核心或历史夹具继续使用原文本界面。交付补丁仍使用原 `WorkspaceRuntime.diff()` 路径，独立于浏览器预览的文本限制。
