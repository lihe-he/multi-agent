# Agent Studio 界面

React、TypeScript、Vite 中文桌面界面。应用页面直接访问本地 Java 核心，不包含演示任务或模拟执行。

## 本地开发

使用 Node.js 22.12 及以上（本次验证 Node.js 24.18.0），在本目录运行：

```sh
npm ci
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`，开发代理将 `/api` 转发至 `http://127.0.0.1:18765`。在「连接设置」填写核心启动令牌，也可通过 `VITE_API_TOKEN` 开发环境变量提供。令牌仅存浏览器本次会话，不应写入版本控制。

Electron 通过 `window.workbench.getConnection()` 自动提供 `{baseUrl, token}`，还支持 `selectDirectory()` 和 `openPath(path)` 可选桥接。

## 页面与可操作范围

- 项目总览：导入 Git 项目、切换项目、扫描索引、查看项目模块及真实任务统计。
- 研发任务：完成约定、范围、验证命令、三种模式、路由、预算和硬锁定；确认、暂停、继续、取消、人工验收及交付包导出。
- 任务详情：依赖阶段、固定上下文与路由快照、版本、代码差异、独立审查、所有验证证据。事件按游标续读，界面最多保留最近 500 条，完整记录保存在核心及交付包。
- 恢复操作：暂停状态调整根预算；重新验证当前成果；结果未知时必须由用户勾选进程停止、副作用核对并填写依据，才提交人工核对。
- 项目记忆：创建、修订、停用、启用和删除；代码关键词检索与覆盖诊断。
- 资源设置：API/Codex/Claude 路由配置与能力探测；API 密钥仅由核心在本次会话保存；职责模板版本编辑、导入预览与导出。
- MCP 工具：HTTP/stdio 服务配置、项目与工具授权清单、真实初始化和工具发现、身份及定义版本，以及对外只读项目 MCP 地址。外部 MCP 尚未自动注入 Agent 工具循环，界面明确展示这一限制。
- 项目只读令牌：为外部客户端创建、复制及撤销项目限定的 MCP 访问令牌。令牌仅在创建后的当前页面内保留，离开页面不再显示，不写入 localStorage/sessionStorage，核心重启后失效；不能访问其他项目或平台管理接口。界面不会向外部客户端展示或复制桌面管理令牌。

真正的执行边界、模式保证和发布完成度由核心能力声明及计划验收记录决定。界面不会将未验证或结果未知的执行自动改为成功。

## 构建与验证

```sh
npm run build
npm run test:ui
```

生产文件输出至 `dist/`。生产 CSP 限定自身脚本和本机连接；开发模式额外允许 Vite 的本机 HMR 与 React 预加载脚本。

Playwright 测试仅使用明确的接口夹具，验证任务参数提交、不会自动批准、刷新后详情证据不丢失、人工核对流程、窄窗口导航及页面异常。它们不能代替真实 Java/CLI/API 的端到端验收。Windows 默认使用已安装的 Edge；其他平台需要先安装 Playwright Chromium。可通过 `PLAYWRIGHT_CHANNEL` 指定已安装的浏览器。
